01

账号、余额与 API Key

API Key 是客户端访问中转服务的凭证。建议为不同客户端分别创建密钥，便于查看用量和单独停用。

1

注册并登录

进入官网完成注册。已有账号可直接登录控制台。

2

充值或兑换

使用前确认余额充足，避免请求因额度不足而中断。

3

创建 API Key

进入“API Key”页面，设置名称、可用模型和额度限制后保存。

!
密钥只会完整显示一次

创建后请立即复制保存。如怀疑泄露，请删除旧密钥并重新创建。

02

不同软件的字段名称可能略有差异，但核心参数始终是请求地址、API Key 和模型名称。

03

聊天客户端配置

适用于 Cherry Studio、Chatbox、NextChat、Open WebUI 等支持自定义 OpenAI 接口的客户端。

  1. 打开模型服务设置

    进入客户端设置，找到模型供应商或模型服务。

  2. 添加自定义供应商

    选择 OpenAI 或 OpenAI Compatible，供应商名称可以自定义。

  3. 填写接口信息

    Base URL 填写 ，再粘贴 API Key。

  4. 添加模型

    优先使用“获取模型”功能；无法获取时，手动填写网站模型广场中的模型 ID。

  5. 保存并测试

    启用供应商，新建对话并发送简短消息。

04

Codex 与 Claude Code

推荐从控制台的 API Key 页面使用“导入到 CC Switch”，可减少手动编辑配置文件造成的错误。

通过 CC Switch 导入

  1. 创建专用 API Key

    建议为编程工具单独创建密钥并设置合理额度。

  2. 打开密钥操作菜单

    选择“导入到 CC Switch”。

  3. 选择应用和模型

    选择 Codex 或 Claude，并从当前可用模型中选择主模型。

  4. 确认导入并启用

    在 CC Switch 中保存、启用供应商，然后重新打开对应客户端。

Codex CLI 手动配置

Codex 用户级配置位于 ~/.codex/config.toml。自定义中转必须使用支持 Responses API 的模型和渠道。

~/.codex/config.toml

再将密钥写入环境变量：export GATEWAY_API_KEY="sk-你的密钥"。不要把真实密钥直接写进配置文件或代码仓库。

06

图片、音频与视频接口

多媒体模型的接口路径和参数与聊天模型不同。调用前先在模型广场确认模型支持的端点类型。

能力 常见接口 注意事项
图片生成 /v1/images/generations 确认尺寸、质量和张数限制。
语音合成 /v1/audio/speech 确认音色和输出格式是否受支持。
语音转写 /v1/audio/transcriptions 通常需要 multipart 文件上传。
视频任务 以模型详情页为准 视频通常为异步任务，需要查询任务状态。
!
客户端支持不代表模型支持

如果请求返回“不支持的端点”，请检查所选模型能力，而不是反复更换 API Key。

07

模型选择与计费说明

  • 模型 ID以模型广场展示为准，名称和大小写必须完全一致。
  • 价格不同模型可能按输入、输出、图片、时长或任务次数计费。
  • 分组密钥所属分组会影响可用渠道与倍率。
  • 用量可在使用日志中查看模型、令牌数、耗时和扣费明细。
08

常见问题排查

401：未授权或 API Key 无效

重新复制完整密钥，检查是否有空格、换行或缺少 sk- 前缀，并确认密钥未被禁用。

403：没有权限使用模型

检查 API Key 的模型限制、分组权限和账号状态，并确认模型对当前分组开放。

404：接口或模型不存在

检查 Base URL 是否重复添加 /v1，并确认模型 ID 与模型广场完全一致。

429：额度不足或请求过快

查看余额与密钥额度，降低并发和请求频率；如为上游繁忙，可稍后重试。

请求超时、无响应或中途断开

检查本地网络、代理和防火墙，适当增加客户端超时时间，并尝试更换可用模型或渠道。

模型列表获取失败

先手动添加模型 ID。部分客户端的“获取模型”接口或鉴权方式可能与自定义中转不兼容。

09

API Key 安全建议

  • 不要在截图、群聊、工单或公开视频中暴露完整密钥。
  • 不要将密钥提交到 GitHub、Gitee 等公开代码仓库。
  • 为不同设备和客户端创建独立密钥，并设置额度或模型限制。
  • 定期查看使用日志，发现异常调用后立即删除旧密钥。
  • 服务端通过环境变量保存密钥，浏览器前端不要直接持有长期密钥。
